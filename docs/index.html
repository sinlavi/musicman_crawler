High-Performance Distributed Music Processing Engine

Automated queue polling, iTunes & YouTube Music audio extraction, HD artwork embedding, ID3 tagging, voice previews, and instant Telegram channel delivery.

🌐 Access Project Instance (mm.3rah.ir) ⭐ View on GitHub

Engineered for Scale & Precision

Everything needed to process, enrich, and deliver digital music at scale.

⚡

Distributed Modulo Sharding

Scales across unlimited parallel instances using deterministic download_id % TOTAL_INSTANCES sharding. Eliminates task collisions without external broker overhead.

🎨

HD Artwork & ID3 Enrichment

Injects high-resolution cover art (up to 3000x3000px), title, artist, album, release year, genre, and lyrics directly into standard ID3 audio tags.

🎙️

Voice Preview Generation

Extracts high-quality 30-second audio snippets tailored for Telegram voice previews, enabling instant audio listening before full download.

🔄

Self-Healing Queue Recovery

Primary instances detect crashed or interrupted tasks and reset stuck downloads back to pending status with exponential backoff on technical errors.

🌐

Cloudflare WARP Integration

Built-in support for Cloudflare WARP SOCKS5 proxy routing to bypass geo-restrictions and platform rate limiting seamlessly.

📜

Synced Lyrics Fetching

Queries LRCLIB and lyrics services for synchronized (.lrc) and plain text lyrics, embedding them directly into track files.
