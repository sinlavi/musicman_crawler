User & API Guide

How to Work with mm.3rah.ir

Learn how the web service queue, distributed crawlers, and Telegram delivery engine process requests end-to-end.

1️⃣

Queue Submission

Users submit music download requests through the main web application at mm.3rah.ir or connected Telegram bot interfaces.

2️⃣

Distributed Worker Sharding

Distributed crawler instances poll the API queue using modulo sharding (download_id % TOTAL_INSTANCES) to fetch tasks without lock collisions.

3️⃣

Dual Bitrate Processing

Tracks are downloaded at maximum resolution (320 kbps), tagged with HD covers and lyrics, and automatically converted to produce both 192 kbps and 320 kbps audio files.

4️⃣

Telegram & API Upload

Processed audio files and instant 30s voice previews are delivered directly to Telegram channels and mirrored back to backend storage.

Engineered for Scale & Precision

Everything needed to process, enrich, and deliver digital music at scale.

Distributed Modulo Sharding

Scales across unlimited parallel instances using deterministic download_id % TOTAL_INSTANCES sharding. Eliminates task collisions without external broker overhead.

HD Artwork & ID3 Enrichment

Injects high-resolution cover art (up to 3000x3000px), title, artist, album, release year, genre, and lyrics directly into standard ID3 audio tags.

Dual Quality (192 + 320 kbps)

Automatically generates and uploads both 192 kbps and 320 kbps audio formats for every track, catering to all network conditions.

Self-Healing Queue Recovery

Primary instances detect crashed or interrupted tasks and reset stuck downloads back to pending status with exponential backoff on technical errors.

Cloudflare WARP Integration

Built-in support for Cloudflare WARP SOCKS5 proxy routing to bypass geo-restrictions and platform rate limiting seamlessly.

Synced Lyrics Fetching

Queries LRCLIB and lyrics services for synchronized (.lrc) and plain text lyrics, embedding them directly into track files.

System Architecture Flow

Distributed workflow from queue polling to Telegram channel broadcast.
